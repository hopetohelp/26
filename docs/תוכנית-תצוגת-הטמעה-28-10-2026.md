# תצוגת ההטמעה של תוצאות ומה השתנה — 28/10/2026

1. **הבעיה/הפעולה:** הבעלים ביקש קישורי הטמעה במצב בהיר או לפי המשתמש לשני המסכים.
2. **מה בוצע:** בענף העבודה נוספה בחירה בהיר / לפי העדפת המשתמש בקוד ההטמעה. ברירת המחדל בהירה גם בקישורים קיימים; `theme=auto` מכבד את בחירת הגולש באתר ובהיעדרה את המכשיר. מנגנון התצורה המשותף משמש גם בהטמעה, מגיב לשינויי מכשיר וכתובת ואינו משנה את ההעדפה השמורה. התצורה חלה לפני הציור הראשון, גם כשהאחסון חסום; `theme=dark` נשמר לתאימות. עברו בניית נתונים דטרמיניסטית ללא שינוי, בדיקות המודל, התחזית והאיכות, בדיקת טיפוסים, 905 בדיקות, בניית האתר ובדיקת הנתונים הפתוחים. בדפדפן Chromium מקומי עברו שני המסכים ברוחב 390 ו-1280: תצורה בהירה וקבועה, העדפה שמורה, שינוי מכשיר וכתובת, החלפת קוד ההטמעה, קישור למקור ואחסון חסום; ללא שגיאות JavaScript וללא גלילה אופקית. נפתח [PR 577](https://github.com/hopetohelp/26/pull/577).
3. **ממתין לביצוע:** בדיקות CI, מיזוג ופרסום; אימות האתר החי לאחר הפריסה.
4. **נדחה:** אין.
