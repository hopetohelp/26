הגרסה הקיימת (צבעי הגזרה): `docs/תוכנית-סרטון-נתונים-26-10-2026.md`. כל מה שלא נאמר כאן — זהה לה.

## מי מקבל איזו גרסה
- חבר בגזרה (`useHagzara(session)` מחזיר קבוצה) ⇐ הגרסה הקיימת, בלי שינוי.
- כל השאר ⇐ הגרסה הכללית. ההחלטה ב-`PromoVideo.tsx` (`group` כבר מגיע מ-`ShareCard`; `null` = לא חבר).
- מימוש: שדה `theme: "hagzara" | "site"` ב-`PromoData`; כל צבע, הסמל והמסך החמישי נגזרים ממנו. המוזיקה, התזמון, הספירה וחלון השיתוף — משותפים.

## 2. הפתיח — קלפי במקום סמל הגזרה
ציור וקטורי בקנבס (בלי תמונה ובלי AI): קופסת קלפי כחולה-לבנה בפרספקטיבה קלה, עם חריץ; מעטפה לבנה צונחת לתוך החריץ בתחילת הפריים (פריים 0 כבר מראה קלפי + כותרת — תמונת התצוגה ברשתות). אותן טבעות הדף ואותה "צלילה" לתוך החריץ במעבר למסך 2. הכותרת: "מחר התוצאות. / הנה מה שכולם צופים." (כמו היום).

## 3. מסך 5 (במקום "המפלגות החרדיות") — שלוש אפשרויות לבחירת הבעלים
אותו מבנה ותזמון (10.5–13.5, קפוא 2 שניות לקריאה), אותן עוגות מהמסך הקודם. רק מה ש"יוצא" מהעוגה והכרטיסים משתנים.

**א. "הדרך ל-61"** — שני הגושים הגדולים (נתניהו, אייזנקוט) יוצאים יחד מהעוגה; בכל כרטיס (סקרים / ניחושים / הניחוש שלי): כמה מנדטים לכל גוש, וכמה **חסרים לו ל-61** ("חסרים 24"). עובדתי, בלי המלצה; מחובר לנתונים כמו שהכללים דורשים ("חסרים להם 8 מנדטים לרוב").

**ב. "מי עובר את אחוז החסימה?"** — הרשימות שקרובות לאחוז החסימה (עד ~6 מנדטים בסקרים או בניחושים): לכל אחת — הסקרים מול הניחושים, ותג "עוברת / מתחת לסף" (3.25% ≈ 4 מנדטים). במקום פרוסה יוצאת — כרטיס רשימות. מחושב כולו מנתוני הגרף.

**ג. "איפה כולם מסכימים"** — המשלים של "הפער הגדול ביותר": הרשימה שבה ממוצע הסקרים וממוצע הניחושים הכי קרובים, עם שתי הקפסולות וההפרש ("פער 0.2"). מעביר את מסך 5 מהעוגות לגרף; העוגות נגמרות במסך 4.

המלצה: **א** — נשאר בתוך העוגות (המעבר הכי חלק), והשאלה "מי מגיע ל-61" היא הנושא המרכזי ערב הבחירות.

## איך ממשיכים (לסשן הבא)
1. הבעלים בוחר א/ב/ג.
2. מימוש ב-`src/lib/promoVideo.ts`: `theme` ב-`PromoData`; פלטת צבעים לפי theme (היום `PC` + `BLOC_COLORS` קבועים — להפוך לפונקציה); `drawBallot()` לפתיח; מסך 5 לפי הבחירה. `buildPromoData` ב-`src/pages/simple/PromoVideo.tsx`: `theme: group ? "hagzara" : "site"`.
3. תמונות לאישור **לפני** בנייה (פתיח, גרף, עוגות, מסך 5, סוף; עם ובלי "הניחוש שלי"), ואז סרטון מלא לאישור, ואז PR ⇐ CI ⇐ מיזוג (הבעלים אישר בעבר מיזוג ישיר לאחר אישור).
4. כלי הבדיקה המקומי: `Content-creator/tools/promo_harness/` (מצייר פריימים ובונה סרטון בכרומיום מהקוד של ריפו 26; ההוראות בקובץ README שם).
