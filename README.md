# בחירות 2026 — ניתוח

אתר לניתוח הבחירות לכנסת ה-26 (27.10.2026): תוצאות אמת של מערכות הבחירות 2019–2022, ארכיון הסקרים של המחזור, מגמות, דיוק הסקרים במערכות הקודמות מול התוצאות, ומחשבון מנדטים שמממש את חוק הבחירות — אחוז החסימה, הסכמי העודפים ושיטת באדר-עופר.

**האתר אינו עורך סקרים ואינו ממליץ על אף רשימה.**

## מה יש כאן

| תיקייה | תוכן |
|---|---|
| `raw/` | חומר הגלם כפי שהורד: תוצאות ועדת הבחירות (כנסות 21–25) וטבלאות הסקרים מוויקיפדיה |
| `pipeline/` | הסקריפטים שבונים את `src/data/*.json` מחומר הגלם, ובדיקת ההקפאה |
| `src/engine/` | מנוע חלוקת המנדטים (סעיפים 81–82 לחוק הבחירות לכנסת) ובדיקותיו |
| `src/lib/history.ts` | חישובי "דיוק הסקרים בעבר" (סקרי 2019–2022 מול התוצאות) ובדיקותיהם |
| `src/pages/` | עמודי האתר |
| `src/lib/theme.ts` · `src/index.css` | שלושת העיצובים (צעיר · מקצועי · חדשותי) — הטוקנים והבחירה |
| `worker/feedback/` | השרת הקטן של כפתור ההערות (Cloudflare Worker + מאגר D1 פרטי) |
| `PRODUCT.md` · `DESIGN.md` | למי האתר ואיך הוא נראה — לקרוא לפני כל שינוי עיצוב |

## הרצה מקומית

```bash
npm ci
python3 pipeline/build_data.py   # בונה את קובצי הנתונים
npm test                         # בדיקות המנוע (שחזור 5 מערכות + מקרי קצה) ודיוק הסקרים
python3 pipeline/test_freeze.py  # בדיקות ההקפאה בשעון מזויף
python3 pipeline/test_model.py   # המודל: מנוע מהיר, תצפית, בדיקת עבר עדכנית
npm run dev
```

## כללים

- **מנוע המנדטים** חייב לשחזר בדיוק את התוצאות הרשמיות של כל מערכות הבחירות ב-`src/data/results.json` — הבנייה נכשלת אחרת.
- **חוק הבחירות (דרכי תעמולה), סעיף 16ה:** סקר נכנס לאתר 24 שעות אחרי פרסומו הראשון; מתום יום שישי 23.10.2026 ועד סגירת הקלפיות — אין סקרים חדשים, ובכל עמוד הודעה שהסקרים אינם עדכניים. נאכף בצינור הנתונים ונבדק ב-CI.
- **שקיפות:** כל מספר מחושב באתר מגיע עם מקור, "נכון ל-", ההנחה המרכזית וקישור לעמוד השיטה.

## הערות בלי מייל

כפתור "הערה?" שולח טקסט קצר ל-`worker/feedback/`, שנפרס ל-Cloudflare בכל דחיפה ל-`main` (‏`.github/workflows/feedback-worker.yml`) ושומר אותו במאגר D1 פרטי. לא נשמרים מייל, שם או כתובת IP — רק מפתח יומי חד-כיווני להגבלת הצפה (8 הערות ביום).
- הפריסה צריכה את הסוד `CLOUDFLARE_API_TOKEN` בריפו. בלעדיו — הפריסה מדלגת בשקט.
- הכפתור מוצג רק כשמשתנה הבנייה `VITE_FEEDBACK_URL` מוגדר (‏`.github/workflows/pages.yml`).
