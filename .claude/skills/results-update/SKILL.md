# עדכון תוצאות הבחירות באתר

הכרעת בעלים 27.10.2026. מעדכנים שלושה נתונים במסך "תוצאות" (`/results-2026`), והאתר נבנה ומתפרסם מהם:

| נתון | קובץ | מקור |
|---|---|---|
| אחוז הצבעה | `public/turnout.json` | מפת ההצבעה של ועדת הבחירות (mapvotes) |
| אחוז הקולות שנספרו ("נספרו") | `raw/results-2026.json` ← `counted` | ועדת הבחירות; אין גישה ⇐ הברומטר של JDN; ואחריו ויקיפדיה העברית |
| קולות ⇐ מנדטים לכל רשימה | `raw/results-2026.json` ← `seats`, `pct` | ועדת הבחירות; אין גישה ⇐ הברומטר של JDN; ואחריו ויקיפדיה העברית |

השורה במסך היא `אחוז הצבעה: X% בחירות קודמות: Y% נספרו: Z%`, בעשירית האחוז (`TurnoutCard` ב-`src/pages/simple/GuessAccuracy.tsx`):
- **X:** המצביעים מהמפה, מתוך בעלי זכות הבחירה הרשמיים (`registry.k26`, ‏7,336,553).
- **Y:** אחוז ההצבעה הסופי ב-2022 מהתוצאות הרשמיות. **לא** `prev_percent` של המפה, שהוא העדכון הקודם של אותו יום.
- **Z:** מוצג רק כש-`counted` ידוע.

## 🔴 גבולות
- **שבת:** לא רץ בין שישי 16:00 למוצאי שבת 20:00 (שעון ישראל). עונים "שבת — לא בוצע דבר" ומסיימים.
- **סריקה:** גלישה רגילה בלבד. אתר שחוסם בצד השרת (403, 404 של gov.il, בדיקת אנושיות) — לא עוקפים ולא משתמשים בשירותי עקיפה. עוברים למקור הבא.
- **מספרים:** מעתיקים רק מהמקור עצמו. לא מנחשים, לא משלימים ולא "מתקנים" סכום.
- **מנדטים:** תמיד מחושבים במנוע החוק של האתר: אחוז חסימה 3.25%, הסכמי עודפים מ-`meta.agreements2026`, באדר-עופר (`pipeline/bader_ofer.py`). אף פעם לא מעתיקים מספרי מנדטים מהמקור.
- **תווית:** ויקיפדיה ⇐ "לא אומת". ועדת הבחירות ⇐ "ועדת הבחירות המרכזית". `status: "final"` רק כשהוועדה מפרסמת תוצאות סופיות.
- **קוד:** לא משנים קוד. רק את שני קובצי הנתונים שבטבלה.

## שלב 2 — אחוז הצבעה (מפת ההצבעה)
```bash
curl --fail -s --max-time 60 "https://mapvotes.bechirot.gov.il/data/votes/latest/municipal_data.json" -o /tmp/turnout.json \
 && node -e 'const d=JSON.parse(require("fs").readFileSync("/tmp/turnout.json","utf8")); const t=d.total; if(!t||typeof t.percent!=="number") process.exit(1); require("fs").writeFileSync("public/turnout.json", JSON.stringify({ time: d.time, generated: d.generated, total: t, source: "https://mapvotes.bechirot.gov.il" }))'
```
ההורדה נכשלה ⇐ הקובץ נשאר כמו שהוא, ונרשמת שורה בסיכום.

## שלב 3 — קולות ואחוז שנספר
> **סדר המקורות (הכרעת בעלים 28.10.2026):** קודם הברומטר של JDN (סעיף 2), ואם הוא לא נגיש או ריק — ויקיפדיה (סעיף 3). דף התוצאות של הוועדה (סעיף 1) מחזיר 404 מחוץ לישראל, ולכן לא נבדק בריצה. הריצות: כל רבע שעה עגולה (:00, :15, :30, :45), מסשן ייעודי אחד.
> **"נספרו"** = הקולות שנספרו (כשרים ופסולים) מתוך כלל בעלי זכות הבחירה (`registry.k26`, ‏7,336,553; הכרעת בעלים 28.10.2026). השעה בסוגריים במסך היא שעת העדכון האחרון שבו הנתונים השתנו.

1. **ועדת הבחירות** — `https://votes26.bechirot.gov.il/nationalresults?lang=he`, ב-Playwright (`require('playwright')`, `chromium.launch()`):
   - מהדף מעתיקים: אחוז הקולות שנספרו (או קלפיות שנספרו מתוך הכלל), הקולות הכשרים, והקולות לכל רשימה.
   - כותבים קובץ JSON כמו בדוגמה, עם מזהי הרשימות מ-`src/data/meta.json` ← `lists2026`. רשימה שלא מופיעה במקור — לא כותבים אותה.
   ```json
   {"votes": {"likud": 123456, "yashar": 120000}, "valid": 1500000, "counted": 18.4,
    "source": "ועדת הבחירות המרכזית — votes26.bechirot.gov.il (ספירה חלקית)", "status": "partial"}
   ```
   - מריצים: `python3 pipeline/fetch_results_2026.py --votes /tmp/votes.json`
   - הדף חסום או לא נמצא (gov.il מחזיר 404 או 403 מחוץ לישראל) ⇐ לא עוקפים, עוברים לסעיף 2.
2. **הברומטר של JDN** (הכרעת בעלים 27.10.2026) — `https://elections.jdn.co.il/data/count-live.json`, נתוני ועדת הבחירות לפי קלפי:
   `python3 pipeline/fetch_results_2026.py --jdn`
   - הסקריפט ממפה את מזהי JDN למזהי האתר (`JDN_IDS`) ומשתמש בקולות הכשרים שנספרו לחישוב אחוז החסימה.
   - "נספרו" = הקולות שנספרו מתוך כלל בעלי זכות הבחירה. התווית: "ועדת הבחירות המרכזית דרך הברומטר של JDN — לא אומת".
   - בספירה זעירה העיגול עלול לתת 119 או 121 מנדטים ⇐ הסקריפט מעדכן רק את "נספרו" ומשאיר את המנדטים. זה תקין.
   - רשימה חדשה ב-JDN שאינה ב-`JDN_IDS` ⇐ נרשמת בסיכום לבעלים (לא משנים קוד בריצה).
   - הקובץ לא נגיש או ריק ⇐ עוברים לסעיף 3.
3. **ויקיפדיה העברית** (הערך "הבחירות לכנסת העשרים ושש", פרק "תוצאות"): `python3 pipeline/fetch_results_2026.py`
   - הסקריפט קורא את טבלת הקולות ואת "נספרו X%" (או "נספרו X אחוז"), ומחשב את המנדטים.
   - אין עדיין טבלה, אבל בערך כתוב אחוז שנספר ⇐ מעדכנים ידנית רק את `counted` ב-`raw/results-2026.json`, ומשאירים את `status` ואת `seats`.
4. **בדיקה:**
   - סך המנדטים 120.
   - אין רשימה עם 1–3 מנדטים.
   - `counted` בין 0 ל-100.
   - הסקריפט מסרב לכתוב כשהסך אינו 120. אחרי סירוב — לא מתקנים ידנית.
