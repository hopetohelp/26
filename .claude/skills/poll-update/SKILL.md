# חיפוש ועדכון סקרים — מכל מקום שבו מתפרסם סקר

המסמך המחייב הוא `docs/נוהל-עדכון-יומי.md`. הסקיל הזה מוסיף לו **איפה לחפש** ו**איך להעתיק** נתונים
בלי לחשוב מחדש בכל פעם. סתירה ⇐ הנוהל קובע.

## 🔴 גבולות (לפני הכול)
- **תאריכים:** קליטת סקר חדש — עד 23.10.2026 כולל. מ-24.10 החוק אוסר פרסום סקרים חדשים ⇐ לא מחפשים ולא מוסיפים.
- **שבת:** לא רץ בין שישי 16:00 למוצאי שבת 20:00 (שעון ישראל).
- **אתרים שאוסרים סריקה אוטומטית** (ערוץ 16 ואחרים שברשימה למטה) — לא סורקים, לא עוקפים חסימה, לא משתמשים בשירותי עקיפה. מחפשים את אותו סקר באתר אחר שמתיר גלישה רגילה.
- **gov.il** חוסם כלים אוטומטיים (Cloudflare) ⇐ לא עוקפים. רק קישור ישיר לדוח PDF שמופיע במקור אחר, או העתקה ידנית של הבעלים.
- מספרים מעתיקים **רק** מהפרסום עצמו (הכתבה/הגרפיקה/הדוח). לא מנחשים, לא משלימים, לא "מתקנים" סכום. סקר לא שלם ⇐ לא נכנס, ונרשם בסיכום.
- לא משנים קוד. חריג יחיד: שם בעברית למכון/גוף מזמין חדש ב-`FIRM_HE` / `PUB_HE` (`pipeline/build_data.py`).

## שלב 1 — מה כבר יש באתר
```bash
git checkout main && git pull -q origin main
python3 - <<'PY'
import json; p=json.load(open('src/data/polls.json'))
polls = p['polls'] if isinstance(p, dict) else p
for x in sorted(polls, key=lambda x: x['end'], reverse=True)[:25]:
    print(x['end'], x['firm'], '|', x['publisher'], '|', x['id'])
PY
```
סקר נחשב "קיים" אם יש סקר עם **אותו מכון, אותו גוף מזמין ואותו תאריך סיום** (גם אם המזהה שונה במעט).

## שלב 3 — מה מעתיקים מכל סקר (רשימה סגורה)
| שדה | מאיפה בכתבה | הערה |
|---|---|---|
| `firm` | שם המכון — **באנגלית, כמו בוויקיפדיה ובטבלת `FIRM_HE`** (למשל `Direct Polls`, `LRI+P4A`, `MP+TM+SN+A`, `SF+ND`, `Kantar`) | שם זהה לוויקיפדיה = המזהה זהה, וכך אין כפילות כשוויקיפדיה תוסיף את הסקר |
| `publisher` | הגוף המזמין, באנגלית לפי `PUB_HE` (`Channel 13`, `Maariv`, `i24 News`, `Kan 11`, `Channel 14`, `Channel 12`) | |
| `start`, `end` | ימי השדה ("הסקר נערך ב...") ; לא נמסר ⇐ שניהם = יום הפרסום, ולרשום זאת ב-`note` | פורמט `YYYY-MM-DD` |
| `sample` | "השתתפו N משיבים" | מספר שלם; לא נמסר ⇐ `null` ולרשום ב-`note` |
| `values` | מנדטים לכל רשימה: `{"likud": {"s": 26}}`; רשימה מתחת לחסימה עם אחוז: `{"p": 2.3}` | מפתחות **רק** מתוך `PARTY_KEY` ב-`pipeline/build_data.py`. סכום המנדטים חייב להיות **בדיוק 120** |
| `urls` | קישור לכתבה המקורית (ואם יש — גם לדוח gov.il) | |
| `publishedAt` | שעת הפרסום עם אזור זמן: `2026-10-12T20:05:00+03:00` | חובה אזור זמן |
| `verified` | `true` רק אם הנתונים הועתקו מהפרסום הראשוני עצמו | |
| `note` | בעברית: מה הושווה, מה חסר, ממה הועתק | |

המזהה: `<end>-<slug(firm)>-<slug(publisher)>` — `slug` = אותיות קטנות, כל רצף תווים שאינו אות/ספרה ⇐ `-`.
דוגמה: `2026-10-07-direct-polls-i24-news`. להריץ כדי לוודא:
```bash
python3 -c "import sys; sys.path.insert(0,'pipeline'); from build_data import slug; print(slug('MP+TM+SN+A'))"
```

## שלב 4 — לאן מעתיקים
- **סקר כללי שחסר באתר** ⇐ רשומה חדשה בסוף `raw/direct-polls.json` (לפי הדוגמאות הקיימות שם).
- **סקר על קבוצת אוכלוסייה בלבד** (צעירים, ערבים, מילואימניקים...) ⇐ `raw/subgroup-polls.json` עם שדה `population`. לא נכנס לממוצע.
- **סקר שכבר באתר** ⇐ לא מעתיקים שוב. אם יש פער בין האתר לפרסום ⇐ `raw/corrections.json` (ערך קודם, חדש, מקור) — לעולם לא בשקט.
- **אימות** של כל סקר חדש (גם מוויקיפדיה) ⇐ `raw/verification.json` עם `status`: `match` (מקור ראשוני זהה) · `secondary` (מקור משני זהה בכל המנדטים; לכתוב מה לא אומת) · `mismatch` (פער; לפרט) · `unreachable`.
- **דוח PDF מ-gov.il** שהבעלים הוריד ⇐ `raw/gov/Survey_<מספר>.pdf` ושורה בטבלה ב-`raw/gov/README.md`.

## אתר שחסום לגלישה (403)
כתבת הסקר עצמה חסומה (למשל c14.co.il) ⇐ מחפשים דיווח באתר שמתיר (כיפה `kipa.co.il/חדשות/...`, וואלה, מעריב) עם חיפוש רשת מהסוג `"סקר חדשות 14" מנדטים <תאריך>`, וקוראים אותו עם WebFetch. הבעלים יכול גם להדביק את נוסח הכתבה — זה מקור ראשוני לכל דבר. בודקים: סכום 120, השינוי לעומת הסקר הקודם שבדיווח, וגוש (ימין/אופוזיציה) אם מצוין. מכון לא מוזכר בדיווח ⇐ שם הסדרה לפי סקרי אותו גוף מזמין הקודמים, ונרשם ב-`note` כ"לא אומת".

## שלב 5 — בדיקה, PR, מיזוג
```bash
git checkout -b claude/polls-$(TZ=Asia/Jerusalem date +%F)
python3.11 pipeline/build_data.py     # חובה Python 3.11 (כמו ב-CI; אחרת בדיקת הדטרמיניזם נכשלת). נכשל על סכום ≠ 120 או מפתח רשימה לא מוכר
python3 pipeline/test_model.py && python3 pipeline/test_forecast.py && python3 pipeline/test_direct_polls.py
npx tsc --noEmit -p tsconfig.json && npm test && npm run build
```
- "⚠️ שמות בלי תרגום לעברית" ⇐ להוסיף ל-`FIRM_HE`/`PUB_HE` באותו PR.
- PR עם טבלה: לכל סקר — מכון, מזמין, תאריכים, קישור, מקור ההעתקה (ראשוני/משני), תוצאת ההשוואה.
- מיזוג רק כשה-CI ירוק **על הקומיט שממזגים**. מכון חדש, או סקר שמזיז חציון של רשימה ב-3 מנדטים ומעלה ⇐ PR נפרד שנשאר פתוח לסקירה, ושורה לבעלים.
- לא נמצא שום סקר חדש ⇐ בלי ענף ובלי PR; שורה אחת בסיכום: "נבדקו X מקורות — אין סקר חדש".
