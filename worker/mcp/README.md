# שרת ה-MCP — `elections26-mcp`

עוזר AI (Claude, ChatGPT…) מתחבר לאתר, קורא את נתוניו ועונה בכרטיס בעיצוב האתר (הכרעת בעלים 12.10.2026).

## שתי כתובות
| כתובת | התחברות | מה יש בה |
|---|---|---|
| `https://elections26-mcp.hopetohelp-il.workers.dev/public` | בלי | כל הנתונים הציבוריים (קובצי הנתונים הפתוחים), מחשבון המנדטים, כרטיס התשובה |
| `https://elections26-mcp.hopetohelp-il.workers.dev/mcp` | חשבון האתר (OAuth) | גם הנתונים והפעולות של המשתמש עצמו, ולמנהל — מסך הניהול |

## 🔴 הגבולות
1. **מקור אחד:** נתונים ציבוריים — רק מ-`data/*.json` שבאתר (`lib/site.js`); המחשבון — `src/engine` (`law.ts`, `pctForSeats.ts`); כל נתון אישי וכל פעולה — שרת ההשתתפות. אין כאן חישוב או עותק משלו.
2. **שיחה עם צוות האתר (שלב 3):** `get_my_team_conversation` ו-`send_message_to_team` — רק השיחה של המשתמש עצמו, באותו נתיב בדיוק כמו האזור האישי (שרת ההערות, `kind: "account-support"`), עם סוג הפנייה ושדה המלכודת. שרת ההערות מזהה את העוזר דרך שרת ההשתתפות (`via`) ומסמן את ההודעה במסך הניהול; `docs/נוהל-הערות.md` חל במלואו (טיוטות, השהיה והחסימה במאגר). שיחות של אחרים — רק במסך הניהול.
3. **אותן הרשאות בדיוק:** כל קריאה אישית יוצאת עם כניסת העוזר של המשתמש (`agent_sessions` בשרת ההשתתפות). מה שמותר לה נקבע שם, ברשימה אחת (`worker/crowd/lib/agent.js`) שנבדקת לפני כל נתיב — לא כאן. החריגים (הכרעת בעלים): סיסמה, מייל וחיבור Google · מחיקת החשבון · מחיקת קבוצה והסרת מנהלים · שיחות הצוות של אחרים.
4. **העוזר אינו מקבל את כניסת העוזר עצמה** — רק אסימון של השרת הזה. הכניסה נשמרת מוצפנת (`DATA_KEY`), וסשן הדפדפן אינו מגיע לכאן לעולם.
5. **הכרטיס בודק את כללי האתר** (`lib/answer.js`): עברית; כל מספר עם סוג, תאריך וקישור "איך זה חושב?" לעוגן קיים במילון; בלי המלצה, בלי "מי ינצח", בלי "סיכוי" והמילה האסורה. תשובה עם בעיה נדחית עם כל הבעיות.
6. **בלי פרטים מזהים:** תיעוד השימוש (`usage`) — יום, כלי, סוג הכתובת, שם העוזר ותוצאה. הגבלת קצב — 300 קריאות בשעה לחיבור, 60 לכתובת רשת בכתובת הציבורית (גיבוב בלבד, נמחק אחרי יממה).

## ההתחברות (`lib/oauth.js`)
`/register` (הרשמה דינמית) ⇐ `/authorize` שומר בקשה ומעביר למסך **"חיבור עוזר AI" באתר** (`#/connect?r=…`) ⇐ המשתמש מאשר; המסך מבקש משרת ההשתתפות `POST /auth/delegate` ושולח את כניסת העוזר ל-`/authorize/approve` ⇐ קוד חד-פעמי ⇐ `/token` (PKCE S256, אסימון לשעה ורענון מתחלף). ניתוק ב"החיבורים שלי" באתר ⇐ שרת ההשתתפות עונה 401 ⇐ החיבור נמחק כאן והעוזר מתבקש להתחבר מחדש.

## כלי חדש
1. רשומה ב-`TOOLS` (`lib/tools.js`): שם, `audience` (public · user · admin), `kind` (read · write · destructive), תיאור (באנגלית, למודל), סכמה ו-`run`.
2. כלי אישי שקורא לנתיב חדש בשרת ההשתתפות — גם שורה ב-`AGENT_ROUTES` (`worker/crowd/lib/agent.js`), אחרת הוא נחסם שם.
3. בדיקה ב-`test/mcp.test.js`.

## הכרטיס
`card/card.js` + `card/card.css` ⇐ `node worker/mcp/card/build.mjs` ⇐ `lib/card.generated.js` (אין לערוך ביד). הצבעים נגזרים מ-`src/index.css` (`:root` ו-`[data-dark]`), ובדיקה נכשלת אם הקובץ הנגזר אינו מעודכן. בלי רשת, בלי `innerHTML`; קישור — רק לאתר.

## בדיקות ופריסה
`npx vitest run worker/mcp` — שרת ההשתתפות האמיתי (מאגר מזויף) מול השרת הזה, מקצה לקצה. הפריסה: `.github/workflows/mcp-worker.yml` (מבנה המאגר, פריסה, סודות שנוצרים פעם אחת, ובדיקה שהשרת עונה).
