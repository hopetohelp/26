# אימות סקרי 2026 — חבילות עבודה (סשן ב2, תוכנית 04.11.2026)

תוצרי ביניים בלבד; הצינור אינו קורא את התיקייה הזו. התוצאות מוזגות ל-`raw/verification.json` ול-`raw/corrections.json` בתסריט `merge.py`.

- `batches/bNN.json` — 25 סקרים שאינם מאומתים, לפי הסדר: הסקר האחרון של כל מכון+מזמין, ואחר כך מהחדש לישן.
- `results/bNN.json` — תוצאת האימות לכל סקר בחבילה (המבנה למטה).

## כללים (מחייבים)
- מקור לפי הסדר: (1) הפרסום המקורי — אתר הערוץ/העיתון שהזמין את הסקר; (2) דיווח עצמאי באתר אחר שמצטט את הסקר (וואלה, כיפה, סרוגים, ערוץ 7, זמן ישראל, ynet, ice, JDN, ג'רוזלם פוסט, טיימס אוף ישראל); (3) ויקיפדיה — **לא** מקור אימות.
- אתר שמחזיר 403 / בדיקת אנושיות / Cloudflare — **לא עוקפים** (לא שירותי עקיפה, לא מטמון של צד שלישי לעקיפה). עוברים לדיווח עצמאי.
- מעתיקים מספרים רק מהפרסום עצמו. לא מנחשים ולא משלימים.
- **דוח רשמי לוועדת הבחירות (סעיף 16ה)** — קובצי PDF פתוחים ב-`https://www.gov.il/BlobFolder/dynamiccollectorresultitem/knesset_election<N>/he/סקר בחירות מיום D.M.2026.pdf` (דף הרשימה עצמו חסום — לא נוגעים בו). הדוח הוא מקור רשמי: מנדטים, ימי ושעות השדה, פונים, משיבים, טעות דגימה ⇐ `access: ["official"]`, ובהערה "דוח לוועדה". **אחוזים** בדוח הם לרוב גולמיים — לא רושמים פער באחוזים לפי הדוח בלבד.
- **סקר עם סיומת `-b`/`-c`** שהוא תרחיש נוסף של אותו סקר (שאלה עם הרכב רשימות אחר) — מאמתים את מספרי התרחיש מול הפרסום, ומוסיפים `"scenarioOf": "<מזהה הסקר הראשי>"` והערה.

## מבנה התוצאה (רשומה לכל סקר)
```json
{
  "id": "<מזהה הסקר מהחבילה>",
  "status": "match | secondary | partial | mismatch | unreachable",
  "source": "<הקישור שממנו אומתו המנדטים>",
  "access": ["primary"] | ["secondary"] | ["none"],
  "published": "2026-08-28T06:01:00+03:00 או null",
  "fields": {
    "seats": {"status": "match|conflict", "source": "<קישור>"},
    "dates": {"status": "match|conflict", "source": "<קישור>"},
    "sample": {"status": "match|conflict", "source": "<קישור>"}
  },
  "details": {"sample_respondents": 506, "asked_to_participate": 4116, "moe": "4.4%", "population": "...", "method": "...", "fieldwork": "2026-08-26..2026-08-27", "pollster": "...", "commissioner": "..."},
  "law16E": {"pollster": true, "commissioner": true, "dates": true, "n_participated": true, "n_asked": true, "moe": true, "population": true, "questions": false},
  "diffs": [{"field": "values.likud.s", "from": 25, "to": 26, "source": "<קישור>"}],
  "foundUrl": "<רק לסקר בלי urls: קישור לפרסום המקורי שנמצא>",
  "note": "בעברית: מה הושווה, מול מה, מה לא אומת"
}
```
- `match` — מנדטי **כל** הרשימות זהים לפרסום המקורי (ראשוני). `secondary` — זהים לדיווח עצמאי (לא המקור הראשוני). `partial` — רק חלק מהרשימות נמצאו בפרסום, כולן זהות. `mismatch` — פער (לפרט ב-`diffs` עם ערך קודם/חדש/מקור). `unreachable` — לא נמצא פרסום שאפשר לקרוא.
- `fields` — רק שדה שנבדק במפורש. `dates` = ימי העבודה בשטח (start/end); `sample` = מספר המשיבים.
- `diffs` — רק כשהפרסום הראשוני (או שני דיווחים עצמאיים תואמים) נותן ערך אחר: `values.<key>.s` למנדטים, `sample`, `start`, `end`. אין לרשום פער אם הסקר בפרסום הוא תרחיש אחר.
- `law16E` — אילו מפרטי סעיף 16ה לחוק הבחירות (דרכי תעמולה) הופיעו בפרסום שנקרא: שם עורך הסקר, המזמין, מועדי העריכה, מספר המשתתפים, מספר הפונים, טעות הדגימה, האוכלוסייה, נוסח השאלות.
