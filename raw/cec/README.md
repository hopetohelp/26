**סמל ועדה:** קיים בקובצי 22–26 ⇐ `src/data/committees.json`. בקובצי 19–21 אין את השדה, ואין קובץ רשמי אחר שממפה קלפי לוועדה (באתר votes21 יש רק תוצאות ארציות, יישובים וקלפיות) — **אין מקור רשמי**; לא נגזר מיפוי ממערכת אחרת.
